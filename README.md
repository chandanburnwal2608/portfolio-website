# Chandan Burnwal – Executive Portfolio Website

Personal portfolio website for **Chandan Burnwal**, Director – Technology Consulting at Ernst & Young (EY) and former Chief Information Officer (CIO).

---

## 🚀 Overview

This website showcases over 23 years of enterprise leadership in:
* **Digital Transformation & Strategy:** Multi-cloud roadmaps across Microsoft Azure and Google Cloud Platform (GCP).
* **Enterprise SAP & S/4HANA:** End-to-end suite implementations, supply chain architecture (DP/SNP/PPDS/TM/GATP), and India's first EPC S/4HANA rollout.
* **Industry 4.0 & Digital Twin:** Center of Excellence setup, asset health monitoring, predictive maintenance, and IoT.
* **Enterprise AI & Generative AI:** GTM strategy, production deployments, and automation.
* **Executive Governance:** CIO leadership, CDIO as a Service, IT Center of Excellence, and large-scale program management (150+ team scale).

---

## 🛠️ Technology Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router, Turbopack, React 19)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **Design Philosophy:** Executive Dark Slate theme with clean typography and responsive layout.

---

## 💻 Local Development

To run this website locally on your computer:

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your web browser.
